# FE-170 (P3)

`src/app/modules/messenger/components/group-manage/GroupManage.js` (строки ~81, 91, 98): у активной кнопки одновременно `loading={target===…}` и `disabled={busy}`, поэтому после FE-31 фокус на ней всё равно теряется. Исправление: `disabled={busy && target !== "title"}` (аналогично для `userId` и `meId`); сначала тест на сохранение фокуса. Из ревью FE-31 (2026-10-22).
