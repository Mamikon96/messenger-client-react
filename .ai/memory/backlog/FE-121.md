# FE-121 (P3)

В `src/app/services/wsService.js` счётчик попыток backoff сбрасывается при каждом `open` без удержания: сокет, который открывается и сразу обрывается, переподключается без нарастающей задержки. Сбрасывать после удержания соединения (например, после N секунд или первого кадра); сначала unit-тест. NIT ревью FE-41.
