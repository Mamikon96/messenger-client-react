# FE-134

Найдено ревью FE-132. В `scripts/check-memory.sh` (проверка роутера решений, около строки 189) конвейер `grep -E '^\|' decisions.md | grep -qF "$dn"` при `set -o pipefail`: `grep -q` выходит на первом совпадении, первый `grep` получает SIGPIPE (код 141), конвейер считается неуспешным и срабатывает `fail` «нет строки роутера». Зависит от планировщика, в простое не воспроизводится (0 из 3000), под нагрузкой `npm run accept` один раз сработало (при FE-132). Повторно наблюдалось 2026-10-18 дважды за сессию: «нет строки роутера для decisions/session-context.md» (ошибок 1) при неизменных файлах, повторный запуск проходил. Гипотеза про SIGPIPE остаётся непроверенной.

Сделать: заменить на `grep -F "$dn" >/dev/null` или `grep -qF "$dn" <(grep -E '^\|' …)`; проверить такие же схемы `| grep -q` в `check-memory.sh` (около строк 67–68, 196, 204) и `git-task.sh:51`. Проверить циклом запуска (например, 50 раз подряд). Тест не обязателен: сбой недетерминирован.
