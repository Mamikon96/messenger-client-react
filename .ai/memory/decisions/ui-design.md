# Решения: UI: токены, темы, дизайн

Формат записи и правила — `../decisions.md`. Записи до FE-D51 перенесены из исходного `decisions.md` без изменений.

## FE-D07 — UI: дизайн-токены на CSS custom properties и свой CSS, без UI-библиотек (2026-10-08)
- **Решение:** редизайн UI строится на дизайн-токенах (CSS custom properties: цвета, типографика, отступы, радиусы, тени, анимации). Темы переключаются атрибутом `data-theme` на `<html>`. Компоненты пишем сами, обычный CSS по БЭМ, по одному файлу на компонент. Новых зависимостей нет. Продолжает FE-D02 и `code-style.md`.
- **Почему:** выбор пользователя. Стек не меняется, зависимостей и бандла не прибавляется, тема меняется подменой переменных без перерендера.
- **Альтернативы:** CSS-токены + headless-библиотека (Radix UI) — меньше работы с a11y/фокусом у popover/меню, но новая зависимость (не выбрано); готовая UI-библиотека (MUI/Chakra) — тяжёлая и уходит от «обычного CSS» (не выбрано).

## FE-D08 — UI: три режима темы — светлая, тёмная, «как в системе» (2026-10-08)
- **Решение:** режимы `light` / `dark` / `system`. По умолчанию `system` (следует `prefers-color-scheme`), выбор пользователя хранится в localStorage (это настройка интерфейса, не данные сессии, FE-D04 не нарушается; сбрасывать при logout не нужно). Тема выставляется на `<html data-theme>` до первой отрисовки, без вспышки. Набор токенов рассчитан на добавление новых тем без правок компонентов. Развивает FE-D07.
- **Почему:** выбор пользователя; «как в системе» даёт верный первый визит, остальное — явное управление.
- **Альтернативы:** только светлая/тёмная без автоопределения; несколько акцентных цветовых схем × светлая/тёмная (больше токенов и тестов, не выбрано).

## FE-D09 — UI: визуальное направление «спокойный минимализм» (2026-10-08)
- **Решение:** стиль в духе Linear / Telegram Web: тонкие границы, один акцентный цвет, мягкие радиусы, аккуратная типографика, сдержанные анимации (с учётом `prefers-reduced-motion`). Контраст проверяется в обеих темах. Развивает FE-D07/FE-D08.
- **Почему:** выбор пользователя; одинаково хорошо смотрится в светлой и тёмной теме и проще поддерживать на токенах.
- **Альтернативы:** яркий и игривый (градиенты, цветные аватары — дороже по дизайну и контрасту); плотный деловой в духе Slack (не выбрано).

## FE-D10 — UI: объём редизайна (2026-10-08)
- **Решение:** кроме тем и визуала в задачу входят: адаптив под телефон (на узком экране одна панель за раз — список чатов или диалог, кнопка «назад»); состояния и микровзаимодействия (пустые состояния, скелетоны, автопрокрутка к последнему сообщению, аватары, плавные переходы); новый экран входа (список провайдеров из данных, загрузка, ошибки OAuth) и меню пользователя (аватар, переключатель темы). Отдельного пакета по клавиатуре/доступности нет, но базовые вещи (видимый фокус, Esc в меню/модалках, контраст AA в обеих темах) — часть каждого компонента. Развивает FE-D07…FE-D09.
- **Почему:** выбор пользователя.
- **Альтернативы:** отдельная задача на клавиатуру и a11y (не выбрана; базовый уровень остаётся в критериях компонентов).
