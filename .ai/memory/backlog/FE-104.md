# FE-104 (P3)

Ошибка поля в `Input` (`src/app/modules/ui/input/Input.js`) имеет `role="alert"`, а после ошибки поле получает фокус и `aria-describedby` — часть скринридеров озвучит текст дважды (NIT ревью FE-92). Решить с пользователем, нужен ли `role="alert"` у ошибок полей (вопрос — до реализации); проверка: unit `Input` и e2e с `toHaveAccessibleDescription`; критерий: `npm run accept` = 0.

Тот же класс проблемы — счётчик длины в `Dialog` (`src/app/modules/messenger/components/dialog/Dialog.js`, FE-40): `role="alert"` и одновременно цель `aria-describedby` поля; при превышении лимита возможны двойное озвучивание и повтор на каждое нажатие клавиши (NIT ревью FE-40, гипотеза, на скринридере не проверено). Решать вместе.

Подтверждено QA FE-40 (QA-8, NIT): у счётчика длины `role="alert"`, скринридер может зачитывать его на каждый символ.
