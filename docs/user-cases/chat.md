Индекс и формат кейса — в `docs/user-cases.md`.

## Чаты (CHAT)

### UC-CHAT-01 — Поиск человека и личный чат
Статус: active
Описание: Человек вводит в поле поиска над списком чатов не менее двух символов имени, видит в блоке «Люди» найденных пользователей и нажимает «Написать» у нужного: открывается личный чат с ним. Если такой чат уже есть, открывается он, дубль в списке не появляется. Пока идёт поиск, видно «Поиск…»; если ничего не найдено — «Никого не найдено»; если поиск не удался — сообщение об ошибке.
Шаги: 1. Войти. 2. Ввести в поле поиска имя человека. 3. Нажать «Написать» у найденного.
Ожидается: справа открыт личный чат с выбранным человеком, в списке чатов он присутствует один раз.
API: GET /api/users
API: POST /api/chats

### UC-CHAT-02 — Выбор чата
Статус: active
Описание: Человек щёлкает по чату в списке, и справа открывается переписка именно этого чата; выбранный чат подсвечен.
Шаги: 1. Создать два чата. 2. Щёлкнуть по каждому.
Ожидается: открывается окно выбранного чата, активный чат выделен.

### UC-CHAT-03 — Список чатов с сервера
Статус: active
Описание: После входа человек видит свои чаты с сервера: название (у личного чата — имя собеседника), текст последнего сообщения и число непрочитанных; выше — чаты с более свежей активностью. Пока список загружается, видно «Загрузка чатов…»; если загрузить не удалось — «Не удалось загрузить чаты.» и кнопка «Повторить»; если чатов нет — «Чатов пока нет».
Шаги: 1. Войти. 2. Дождаться загрузки списка. 3. Если загрузка не удалась, нажать «Повторить».
Ожидается: чаты в порядке, который вернул сервер; у чата с непрочитанными видно их число, у остальных числа нет; при сбое — сообщение и кнопка «Повторить», после которой список загружается; при пустом списке — «Чатов пока нет».
API: GET /api/chats

## Запланированные кейсы (planned)

### UC-CHAT-04 — Создание личного чата или группы
Статус: planned
Описание: Человек выбирает из списка пользователей одного собеседника или нескольких и создаёт личный чат или группу с названием. Если личный чат с этим человеком уже есть, открывается он.
Шаги: 1. Открыть создание чата. 2. Выбрать участников (для группы — задать название). 3. Подтвердить.
Ожидается: новый (или уже существующий личный) чат открыт.
API: GET /api/users
API: POST /api/chats

### UC-CHAT-05 — Управление группой
Статус: planned
Описание: Владелец группы может переименовать её и добавлять или убирать участников; любой участник может выйти из группы (кроме владельца).
Шаги: 1. Открыть группу. 2. Переименовать, добавить и убрать участника, выйти.
Ожидается: изменения видны в списке участников и в названии; недопустимые действия показывают понятную ошибку.
API: PATCH /api/chats/:id
API: POST /api/chats/:id/members
API: DELETE /api/chats/:id/members/:userId
