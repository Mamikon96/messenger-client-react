# Память проекта для AI

Проект — только frontend (бэкенда в репозитории нет, SH-D04). Общий индекс — `.ai/README.md`; правила работы с памятью — `.ai/rules/memory-protocol.md`.

```
.ai/memory/
  README.md          # этот файл
  decisions.md       # общие решения проекта (SH-Dxx)
  frontend/
    state.md  tasks.md  decisions.md  architecture.md  auth-contract.md
```

## Файлы
| Файл | Что хранит | Когда читать | Как обновлять |
|---|---|---|---|
| frontend/tasks.md | В работе (с «Осталось») / Бэклог / Сделано (с датой и приёмкой) | всегда при задаче разработки | Двигать задачи между секциями |
| frontend/state.md | Текущее состояние, известные проблемы (с путями к коду), последняя приёмка, фокус | баги, регрессии, выбор следующей задачи | Перезаписывать целиком только после сверки с кодом |
| frontend/architecture.md | Карта кода и потоки данных | новые модули, правка структуры | Править при изменении структуры |
| frontend/decisions.md | Решения по frontend: что, почему, альтернативы | архитектурный выбор, новая технология (искать по заголовкам `## FE-Dxx`) | Только добавлять в конец |
| frontend/auth-contract.md | Контракт auth API (эндпоинты, тело сессии, коды, `auth_error`) | задачи авторизации (FE-10…FE-17), правка apiClient/mock-BFF | Менять только по решению пользователя (запись в `frontend/decisions.md`) |
| decisions.md | Общие решения (процесс, приёмка, память) | вопросы процесса/памяти (по заголовкам `## SH-Dxx`) | Только добавлять в конец |

## Правила актуальности и корректности
- Первая строка после заголовка в `state.md`, `tasks.md`, `architecture.md`: `> Проверено: ГГГГ-ММ-ДД @ <git sha>[+dirty]` — дата и коммит, на которых факты сверены с кодом. Обновляется **только** после реальной сверки.
- Каждое утверждение о проблеме/состоянии содержит путь к коду в обратных кавычках и проверено чтением кода, `grep` или запуском — не по памяти и не по прошлой записи.
- Исправленное из «Известных проблем» удаляется (история — в git и «Сделано»).
- Задача в «В работе» всегда содержит блок «Осталось»; в «Сделано» — дату и результат приёмки.
- ID: задачи `FE-NN`, решения `FE-DNN` / `SH-DNN`. ID не переиспользуются (в том числе после удаления задачи).
- Даты — абсолютные `ГГГГ-ММ-ДД`. Не хранить секреты и то, что очевидно из кода/git.
- Механическая проверка: `bash scripts/check-memory.sh` (входит в `npm run accept`).
