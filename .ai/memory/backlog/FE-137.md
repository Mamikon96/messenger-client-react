# FE-137 (P2)

Плавающий сбой `scripts/check-memory.sh`: изредка выдаёт «нет строки роутера для decisions/session-context.md» (ошибок 1) при неизменных файлах, повторный запуск проходит (наблюдалось 2026-10-18 дважды за сессию). Гипотеза, не проверена: `grep -E '^\|' decisions.md | grep -qF "$dn"` (около строки 189) при `set -o pipefail` завершается по `SIGPIPE`, когда `grep -q` выходит раньше, чем первый `grep` дописал вывод. Исправление: искать без конвейера (`grep -qF` по файлу с шаблоном строки таблицы) во всех таких местах скрипта; проверить циклом запуска (например, 50 раз подряд).
