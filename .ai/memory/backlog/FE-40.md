# FE-40 (P1)

Оптимистичная отправка (`POST /api/chats/:id/messages`): `clientId` через обёртку над `crypto.randomUUID`, статусы `sending`/`sent`/`failed`, ретраи, `429` с `Retry-After`, длина ≤ 4000 кодовых точек, «Повторить» без правки текста, очередь только в памяти (FE-D14), сверка с `message.new` по `clientId`; сначала unit (слайс/thunk/валидация длины) и e2e; критерий: `npm run accept` = 0. Зависит от: FE-39.
