# User-кейсы: Администрирование (ADMIN)

Индекс и формат кейса — в `docs/user-cases.md`.

## Запланированные кейсы (planned)

### UC-ADMIN-01 — Администрирование видно только администратору
Статус: planned
Описание: Раздел управления пользователями есть только у администратора; обычный пользователь его не видит.
Шаги: 1. Войти администратором. 2. Войти обычным пользователем.
Ожидается: у администратора есть вход в раздел администрирования, у обычного пользователя — нет.

### UC-ADMIN-04 — Управление пользователями
Статус: planned
Описание: Администратор видит всех пользователей, может назначить или снять администратора и отключить или включить пользователя. Отключённого сразу выкидывает со всех устройств. Себя изменить нельзя.
Шаги: 1. Открыть список пользователей. 2. Сделать пользователя администратором и снять. 3. Отключить и включить пользователя. 4. Найти свою строку.
Ожидается: изменения отражаются в списке; у своей строки элементов управления нет.
