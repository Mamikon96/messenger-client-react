# FE-173 (P3)

Outbox не должен повторять отправку при ошибке формы ответа (`Error("Некорректный ответ …")` без `status`, см. FE-171): `isRetryable = !error.status || …` в `src/app/reducers/messages.js` считает её сетевым сбоем, и `deliver` делает ещё три повтора (1+2+4 с) до состояния failed. Ошибка детерминированная, повтор бессмыслен. Сначала тест на редьюсер/thunk. Найдено ревью FE-171 (2026-10-22).
