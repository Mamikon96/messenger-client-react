# FE-82 (P3)

`doneCaseIds` в `scripts/check-state.js` берёт первое «Кейсы:» в строке записи `done.md`: если слово встречается в описании до поля, кейсы контракта теряются и при коммите обязательным остаётся только smoke (ревью FE-80, MINOR). Исправление: привязать поле к разделителю записи — `/(?:^|·)\s*Кейсы:([^·]*)/`; сначала тест в `scripts/check-state.test.js` на запись с «Кейсы:» в описании; критерий: `npm run accept` = 0.
