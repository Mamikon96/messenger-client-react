# FE-109 (P3)

Удаление группы владельцем: пункт в шапке группы (только owner) с подтверждением → эндпоинт удаления (форма появится на бэкенде вместе с разрешением пустых групп; без него пустую группу убрать нельзя: owner не может выйти) → убрать чат из стора, сбросить активный чат. У остальных участников — по `chat.removed` (FE-41). Сначала unit и e2e; критерий: `npm run accept` = 0. Зависит от: FE-107, бэкенд BE-52 (удаление группы), контракт эндпоинта (FE-98).
