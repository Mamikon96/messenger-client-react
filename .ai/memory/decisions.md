# Решения проекта: роутер

Тексты решений лежат в `decisions/<тема>.md` (FE-D51). Здесь — таблицы «ID → название → статус → файл»: найти строку, открыть только указанный файл (внутри — заголовок `## ID`). Читать целиком не нужно.

Заменённые решения («ЗАМЕНЕНО») перенесены в `decisions-archive.md` (FE-D41): FE-D06, FE-D30, FE-D32, FE-D33, FE-D34.

`SH-Dxx` — общие решения (процесс, приёмка, память, продукт); `FE-Dxx` — решения по frontend (архитектура, технологии). Нумерации независимы.

## Как добавить решение
1. Дописать запись в конец файла темы `decisions/<тема>.md` (подходящего нет — новый файл). Шаблон:
```
## SH-DNN / FE-DNN — Название (ГГГГ-ММ-ДД)
- **Решение:**
- **Почему:**
- **Альтернативы:**
```
2. Добавить строку в таблицу своей темы ниже (новый файл — новая тема-раздел). Статус: `действует` или `частично заменено <ID>`.
3. `bash scripts/check-memory.sh` = 0 (строка роутера на каждый ID, верный файл, уникальные ID).
