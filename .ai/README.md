# AI-контекст проекта
Принцип: агент читает **только** файлы, нужные для текущей задачи. Маршрутизатор «задача → файлы» — единственный, в `CLAUDE.md` (грузится всегда); здесь — только структура (FE-D27).

```
.ai/
  rules/     # правила работы (как делать): читать по теме, по таблице в CLAUDE.md
  memory/    # состояние проекта (что есть): описание файлов — memory/README.md (бэклог: memory/backlog/, решения: роутер memory/decisions.md → memory/decisions/, архив решений: memory/decisions-archive.md)
  user-cases.sha256  # хэш утверждённого набора user-кейсов: docs/user-cases.md + docs/user-cases/*.md (меняет только пользователь)
```

Файлы с пометкой «Читать:» в первой строке содержат условие применимости — если оно не про вашу задачу, файл не открывать.
Сводку состояния («В работе», последняя приёмка, фокус) в начале сессии печатает hook `SessionStart` (`scripts/session-brief.sh`).
