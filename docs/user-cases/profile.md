# User-кейсы: Профиль (PROFILE)

Индекс и формат кейса — в `docs/user-cases.md`.

## Запланированные кейсы (planned)

### UC-PROFILE-01 — Смена имени в настройках
Статус: planned
Описание: В настройках (пункт «Настройки» в меню пользователя) человек видит свой логин — его поменять нельзя — и может задать имя и фамилию. Имя обязательно, фамилию можно оставить пустой; каждое — не длиннее 64 символов. Новое имя сразу видно в меню.
Шаги: 1. Открыть меню пользователя, выбрать «Настройки». 2. Ввести имя и фамилию, нажать «Сохранить». 3. Очистить имя и попробовать сохранить.
Ожидается: логин показан без возможности изменить; после сохранения в меню новое имя; с пустым именем — подсказка у поля, запрос не уходит.
API: PATCH /api/me

### UC-PROFILE-02 — Смена пароля
Статус: planned
Описание: В настройках человек может сменить пароль, введя текущий и новый. Он остаётся в системе здесь, а на остальных устройствах вход нужно будет выполнить заново. Новый пароль проверяется так же, как при регистрации.
Шаги: 1. Открыть «Настройки». 2. Ввести неверный текущий пароль и новый, нажать «Сменить пароль». 3. Ввести верный текущий и новый пароль.
Ожидается: при неверном текущем — «Неверный текущий пароль», человек остаётся в системе; при верном — «Пароль изменён», человек остаётся в системе, другие его сессии закрыты (UC-SESSION-06).
API: POST /api/me/password
