# FE-138 (P1)

Подкачка старых сообщений при прокрутке `Dialog` к верху без прыжков позиции прокрутки: вызов thunk-а `loadOlderMessages(chatId)` (FE-39, `before` — минимальный загруженный seq), индикатор загрузки и ошибка с «Повторить», остановка при `hasMore: false`. Вынесено из FE-27 решением пользователя 2026-10-18. Тесты до кода: unit `Dialog` и e2e на длинной истории. После выполнения UC-MSG-04 (сейчас planned) — кандидат в active; перевод только с явного разрешения пользователя. Зависит от: FE-27, FE-39.

Условие автопрокрутки (из ревью FE-27): `Dialog` прокручивает вниз только если пользователь был у низа ленты или отправил своё сообщение; подкачка старых сообщений (и приход чужих при чтении истории выше) не должна прыгать вниз. Сейчас эффект в `Dialog.js` прокручивает безусловно при изменении числа сообщений.
