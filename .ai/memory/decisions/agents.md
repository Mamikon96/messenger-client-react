# Решения: Агенты, паттерны и плагины

Формат записи и правила — `../decisions.md`. Записи до FE-D51 перенесены из исходного `decisions.md` без изменений.

## FE-D18 — Паттерны и best practices для `react-engineer` и `react-reviewer` (2026-10-09)
- **Решение:** глобальный скилл `~/.claude/skills/react-patterns` (принципы, таблица паттернов, антипаттерны, критерии серьёзности) подключён к `react-engineer` (шаг «Дизайн» перед реализацией) и `react-reviewer` (раздел «Паттерны, best practices и архитектура», отдельный блок отчёта). Проектные правила — `.ai/rules/patterns.md` (слои, состояние, что считать нарушением); расхождение с `decisions.md`/`architecture.md` — BLOCKER.
- **Почему:** выбор пользователя; ревью должно жёстко проверять паттерны и архитектуру, а не только хуки и ререндеры.
- **Альтернативы:** только проектный файл без глобального скилла; только глобальный скилл без проектных правил — не выбраны.

## FE-D21 — Ревьюер `react-reviewer` работает на модели opus (2026-10-12)
- **Решение:** `react-reviewer` (оценщик) — `model: opus`; `react-engineer` (генератор) остаётся на `sonnet`.
- **Почему:** выбор пользователя по аудиту харнеса (P1.4): оценщик на другой модели, чем генератор, — разные модели ошибаются по-разному, меньше общих слепых зон и пропущенных замечаний.
- **Альтернативы:** оставить `sonnet` — дешевле по токенам, но генератор и оценщик одной модели; не выбрано.

## FE-D22 — Агенты: исправленные глобальные версии и проектные копии в `.claude/agents/` (2026-10-12)
- **Решение:** глобальные агенты (`~/.claude/agents/react-engineer.md`, `react-reviewer.md`, `task-planner.md`, `solution-architect.md`) и скилл `project-memory` очищены от устаревших путей (подкаталог frontend/ в .ai/memory, contracts.md) и противоречий правилам проекта; в репозитории лежат проектные версии `react-engineer` и `react-reviewer` в `.claude/agents/` (имеют приоритет над глобальными) со ссылками на `.ai/rules/` и контракт задачи.
- **Почему:** выбор пользователя по аудиту харнеса (P1.4): устаревшие инструкции агентов вели к поиску несуществующих файлов и к действиям вопреки `ask-user.md`/`tech-approval.md`; проектные копии версионируются и ревьюятся вместе с правилами, глобальные исправлены для других проектов.
- **Альтернативы:** только глобальная правка (вне git, без ревью); только проектные копии (глобальные остаются с ошибками для других проектов); не выбраны.

## FE-D42 — Плагины и агенты, видимые в проекте (2026-10-15)
- **Решение (выбор пользователя):** в `.claude/settings.json` проекта `enabledPlugins` отключает `superpowers` и `code-review` (глобально они остаются); стековые глобальные агенты (`angular-*`, `nestjs-*`, `nextjs-*`, `node-backend-*`, `sql-*`) запрещены в проекте через `permissions.deny` `Agent(...)`; глобальные файлы не меняются.
- **Почему:** процесс superpowers (brainstorming, plans, TDD, finishing-branch) дублирует контракт задачи, `testing.md` и `git-task.sh` и требует вызова скиллов на каждый ответ; у проекта свой `react-reviewer`; стековые агенты к React-проекту не относятся, а их описания попадают в контекст каждой сессии (эффект deny на контекст проверяется замером первого хода).
- **Альтернативы (не выбраны):** оставить superpowers с белым списком скиллов; разнести агентов по проектам (трогает чужие репозитории); оставить как есть.
