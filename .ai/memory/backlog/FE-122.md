# FE-122 (P3)

В `src/app/services/wsService.js` проверка сессии (`checkSession` = `fetchSession`) идёт без `AbortSignal`: `close()` отсекает только колбэк, а запрос продолжается и сам меняет CSRF-токен (`authApi.js`, `setCsrfToken`). Сценарий: выход и быстрый вход во время проверки — поздний ответ старого запроса ставит чужой токен или `null`, следующий POST получает `403 csrf_invalid`. Передавать `AbortSignal` в `checkSession` и отменять в `close()`; сначала unit-тест. Рядом по теме FE-96. MINOR ревью FE-41.
