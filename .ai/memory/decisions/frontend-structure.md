# Решения: Состояние, структура кода, роутинг

Формат записи и правила — `../decisions.md`. Записи до FE-D51 перенесены из исходного `decisions.md` без изменений.

## FE-D01 — Redux Toolkit для состояния (до 2026-10-04, зафиксировано из кода)
- **Решение:** глобальное состояние в RTK-слайсах (`chats`, `activeChat`, `users`), id генерируются `nanoid()` на клиенте.
- **Почему:** нет бэкенда; RTK — стандарт для Redux.
- **Альтернативы:** Context/useReducer (не выбраны, причины не зафиксированы).

## FE-D02 — Структура «модуль = папка с компонентом и CSS» (зафиксировано из кода)
- **Решение:** `app/modules/<name>/Name.js + Name.css`, вложенные части в `components/`; БЭМ-классы с модификаторами `_x`.
- **Почему:** локальность стилей и кода без CSS-in-JS.

## FE-D19 — Правило экспортов: компонент по default, вспомогательное — именованно (2026-10-09)
- **Решение:** файл-компонент, включая вложенные части в `components/`, экспортирует свой компонент через `export default`; именованные экспорты — для вспомогательного (селекторы, утилиты, константы, вспомогательные компоненты). Формулировка в `.ai/rules/code-style.md` уточнена.
- **Почему:** выбор пользователя по вопросу аудита FE-46; прежняя формулировка («именованный для мелких частей в `components/`») была неоднозначной, а текущий код в основном уже следует этому правилу.
- **Альтернативы:** только именованные экспорты везде (лучше для поиска и рефакторинга, но новое правило и миграция); буквальное прочтение прежнего правила (default в `components/` — нарушение) — не выбраны.

## FE-D31 — Маршрутизация: `react-router` 7.x (2026-10-13)
- **Решение:** маршруты SPA (`/invite`, разделы «Мои ключи» и админка) — на `react-router` ветки 7.x (7.18.4 на момент решения: `peerDependencies` react >=18, node >=20). Ветка 8.x не подходит: требует React >= 19.2.7, а проект на React 18.3.1. Возможная доработка под Jest/jsdom CRA (например, полифил `TextEncoder` в `setupTests.js`) — в задаче внедрения.
- **Почему:** выбор пользователя: полноценные адреса разделов, история и прямые ссылки (ссылка-приглашение `PUBLIC_URL/invite#<token>`) вместо самодельного выбора экрана по `location.pathname`.
- **Альтернативы:** собственный мини-роутинг по `window.location.pathname` без зависимостей; `react-router` 8.x с переходом на React 19; не выбраны.

## FE-D58 — Error Boundary: собственный класс-компонент без библиотек (2026-10-22)
- **Решение:** ошибки рендера перехватывает собственный класс-компонент (`getDerivedStateFromError` + `componentDidCatch`), без новых зависимостей. Границы: корень приложения (fallback с кнопкой «Перезагрузить страницу»), экран входа и мессенджер (fallback с кнопкой «Повторить», сбрасывающей границу). Ошибка внутри мессенджера не должна ронять всё приложение.
- **Почему:** выбор пользователя: ~30 строк кода вместо пакета; хуки `react-error-boundary` не нужны.
- **Альтернативы:** `react-error-boundary` (новая зависимость ради небольшого кода); единственная граница на корне (любая ошибка убивает весь UI); не выбраны.
