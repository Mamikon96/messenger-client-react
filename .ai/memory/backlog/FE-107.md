# FE-107 (P2)

«Новая группа» без участников (решение пользователя 2026-10-17): кнопка «Новая группа» в левой панели → форма с одним полем «Название» (1..100 в единицах UTF-16 после trim, проверка до отправки) → `POST /api/chats {type:"group", title, memberIds: []}` → `201` → upsert чата и открыть его (в шапке — кнопка «Пригласить», FE-108). Ошибки `400` по `details`; двойной клик не создаёт две группы; форма очищается и закрывается после успеха. Другим вкладкам владельца `chat.created` не приходит — это известное ограничение (п. 8а.7 контракта). Сначала unit (валидация, thunk `createGroupChat`) и e2e; критерий: `npm run accept` = 0. Зависит от: FE-44, бэкенд BE-51 (пустой `memberIds`). Кейс в `docs/user-cases.md` — с разрешения пользователя.
