# Аудит расхода токенов
Читать: когда пользователь просит аудит токенов / расхода кэша (команда `/token-audit`) и при периодической проверке (раз в 1–2 недели или после изменений харнесса: агенты, hooks, `CLAUDE.md`, правила).
Источник: аудит 2026-10-20. Пересмотреть, когда меняется формат транскриптов Claude Code или `scripts/token-audit.js`.

## Запуск
1. `node scripts/token-audit.js --days 14` (`--days 0` — за всё время; `--dir` — другой каталог транскриптов). Скрипт только читает `~/.claude/projects/<проект>/*.jsonl` и печатает отчёт.
2. Сравнить с предыдущим аудитом (цифры базовой линии — ниже) и посмотреть `/context` в свежей сессии: из чего состоит префикс первого хода.
3. Отчёт пользователю — по разделам ниже, с цифрами и аргументами; домыслы помечать.
4. Найденные проблемы завести в бэклог (`tasks.md`/`queue.md`, файл в `.ai/memory/backlog/`); новые цифры базовой линии обновить в этом файле.

## Что смотреть
- **Формула расхода:** вызовы API × размер контекста. Tool-результаты (текст файлов, вывод команд) — малая доля; не оптимизировать чтение файлов, пока отчёт не покажет обратное.
- **Первый ход** (медиана) — фиксированный префикс, который читается каждым вызовом; рост между аудитами = раздувание `CLAUDE.md`, hook SessionStart, описаний агентов, списка плагинов/MCP. Бюджет первого хода защищает `scripts/token-budget.test.js`.
- **Субагенты по типам:** cache read на запуск и вызовов на запуск (`qa-tester` самый дорогой); запусков `react-reviewer` заметно больше, чем `react-engineer` = лишние раунды ревью.
- **Самые дорогие сессии:** средний контекст выше порога из `context-guard.sh` (Sonnet 90K, Opus 150K) = порог не сработал или сессию не закрыли.
- **Tool-вызовы:** много последовательных Bash вместо одного объединённого.
- **Перезаписи кэша:** редкие (<1% вызовов) — норма; рост = долгие паузы внутри сессии.
- Инструменты вроде graphify / MCP-графов кода не подключать, пока отчёт не покажет, что основная доля уходит на поиск по коду: каждая схема инструмента увеличивает префикс (вывод аудита 2026-10-20). Новая технология — только через `tech-approval.md`.

## Разбивка префикса первого хода (2026-10-20, оценка)
Замер: медиана первого хода основной сессии за 7 дней — 25,9K токенов, субагента — 19,4K (`token-audit.js`). `/context` из агента не запустить, поэтому по компонентам — оценка по размеру файлов (кириллица ≈ 3 байта на токен, ±30%); при расхождении с `/context` в свежей сессии поправить цифры.

| Компонент | Размер | Токены (оценка) | Управляется проектом |
|---|---|---|---|
| Системный промпт и схемы встроенных инструментов Claude Code | — | ≈ 15–17K (остаток от замера) | нет |
| `CLAUDE.md` проекта | 6,6 КБ | ≈ 2,2K | да |

Кандидаты на сокращение (каждый ≤ 1K из 26K, т. е. ≤ 4% префикса): отключить в проекте скилл `react-development` (пересекается с `react-patterns`) и неиспользуемые пользовательские скиллы (`security-review`, `init`, `fewer-permission-prompts`) через `skillOverrides`; сократить `CLAUDE.md` проекта, вынеся таблицу маршрутизации в `.ai/README.md`. Крупных резервов в управляемой части нет: ≈ 65% префикса — встроенный промпт и схемы Claude Code. Вывод: оптимизировать число вызовов (FE-151), а не префикс.
