# FE-44 (P1)

Поиск людей в левой панели и direct-чат из поиска (решение пользователя 2026-10-17, см. `decisions.md`). Заменяет заглушку `JoinForm` и кнопку «Join» в хедере.
- Сервис `usersApi.searchUsers(q, {signal})` → `GET /api/users?q=&limit=` (бэкенд: поиск по `name`, `q` от 2 символов после trim, без себя, `login` в выдаче нет).
- Хук `useUserSearch`: локальное состояние `{query, setQuery, results, status}`, debounce (свой, на `setTimeout`), отмена устаревших запросов через `AbortController`; результаты не кладутся в RTK.
- Presentational `PeopleSearch` (поле с подписью, список `ul`/`li` строк `UserRow` на `Avatar`, состояния loading/empty/error, статус в `aria-live`); действие на строке — prop `getAction(user) → {label, icon, disabled, onClick}`; переиспользуется в FE-108.
- Левая панель: поле поиска над списком чатов; при непустом запросе показывается блок «Люди»; действие строки — `IconButton` «Написать <имя>».
- Thunk `createDirectChat(userId)` в `reducers/chats.js`: `POST /api/chats {type:"direct", userId}`, `201`/`200` → upsert чата из `ChatDto` (без дубля), участники — в `users`, `chatSelected(id)`; `404` (пользователь отключён) — текст ошибки; защита от двойного клика (`pendingUserId`, кнопка в `loading`).
- Удалить `JoinForm`, событие `chatCreated`, кнопку «Join» и связанные тесты; кейс UC-CHAT-01 заменить новым (правка `docs/user-cases.md` — только с разрешения пользователя).
- mock-BFF и e2e (`page.route`): поиск, пустая выдача, ошибка, создание и открытие существующего direct.
Сначала unit (хук, `PeopleSearch`, thunk) и e2e; критерий: `npm run accept` = 0. Зависит от: FE-26 (каркас левой панели), FE-98 (актуальный контракт), бэкенд BE-50 (`GET /api/users?q=`). Из аудита FE-46: границы модулей `header` → `form/join-form` (R-19) снимаются удалением `JoinForm`; закрывает `state.md` п. 1. Поглощает часть FE-05 про `JoinForm`.
